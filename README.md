## 🤖 自动更新

GitHub Actions 每周一 **北京时间 09:00** 抓取周榜，将最新内容写入本页，并把完整快照保存到 `reports/`。也可以在仓库的 **Actions → Weekly GitHub Trending Digest → Run workflow** 手动更新。

本地运行：

```powershell
py -m pip install -r requirements.txt
py scripts/update_weekly.py
```
